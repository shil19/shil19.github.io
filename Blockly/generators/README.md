# 專案名稱：我的個人常用網站導覽頁 🚀



> 這是一個專為手機與電腦優化的極簡網頁，用來整理我每天必看的科技新聞、學習資源與常用工具，點擊即可直接跳轉。



## 🌟 核心功能

- **自適應 RWD 介面**：無論在電腦還是手機上觀看，字體與間距都會自動縮放，完美不跑版。

- **貼心閱讀體驗**：特別加大了文字大小（20px）與項目間距，通勤時在捷運上也能輕鬆點擊。

- **安全新分頁開啟**：所有連結皆設定 `target="_blank"`，不會覆蓋掉原本的導覽頁。



## 🛠️ 使用技術

- **前端網頁**：HTML5、CSS3 (Media Queries 響應式佈局)

- **託管平台**：GitHub Pages (免費靜態網頁架設)
